# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its Code of
Conduct. By participating in this project, you agree to uphold it.

The full text is published here:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Instances of unacceptable behavior may be reported to the project maintainer via
https://github.com/gednyengs. All reports will be reviewed and investigated, and
will be handled with discretion and confidentiality.
